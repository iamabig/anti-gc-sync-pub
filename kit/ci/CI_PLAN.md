# 🧪 AGS-CI 운영 안내 (v1.2)

> 목표: 모든 레포가 커밋·PR 때 계약(C1~C25)을 자동으로 확인한다. **기본값은 필수 검사(🔴면 실패)** 입니다.

## 1. 구조 — 레포는 "버전 한 줄"만 가진다

| 무엇 | 어디 | 바뀔 때 |
|---|---|---|
| AGS-KIT 원본 | 공개 저장소 `kit/agentkit.py`, **태그로 고정** | 두 HQ 합의 + 사용자 승인 → 새 태그 |
| 레포의 버전 | `agent-contract.yml`의 `AGS_KIT_REF` · `AGS_KIT_SHA256` 두 줄 | 설치 스크립트가 바꿈 |
| 레포 안 사본 | `.agentkit/agentkit.py` (로컬 context·check·훅용) | 설치 스크립트가 바꿈 |

CI는 ① 고정 태그의 키를 받아 해시를 확인하고 ② 레포 사본과 해시를 비교한 뒤 ③ 받은 키로 `check --strict`를 실행하고 ④ Job Summary에 열린 결함·남은 구현을 적습니다. 레포 사본을 손으로 고치면 ②에서 실패합니다.

## 2. 단계

| 단계 | CI 동작 | 언제 |
|---|---|---|
| 경고 | `-CIWarnOnly` (`continue-on-error: true`) | 기존 기록이 많아 바로 막히는 레포만, 정리할 때까지 |
| **필수 (기본)** | 🔴면 실패 | 설치 직후부터 |
| 전면 | 브랜치 보호에서 `agent-contract`를 필수 검사로 | 사용자 결정 |

- 🟡 항목은 언제나 경고입니다 (사람 판단이 필요해서 차단하지 않음).
- CI에서는 C22(미커밋)·C24(브랜치)·C25(앞섬)를 건너뜁니다. CI 복제본은 원격과 같기 때문입니다. 이 셋은 **로컬 훅과 컨텍스트 팩**이 잡습니다.

## 3. 비용과 자원
- `ubuntu-latest`, Python 표준 라이브러리만. 수 초. `timeout-minutes: 5`.
- 로컬 PC에는 아무것도 띄우지 않습니다 (8GB 예산 영향 없음).
